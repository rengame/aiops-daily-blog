### Agent 开发

#### 3. Pydantic AI 接入 Azure Durable Task

Microsoft Apps on Azure Blog｜文章发布：**2026-11-16 21:00:00**（13:00:00 UTC，官方订阅）｜首次发现：2026-11-17｜[工程原文](https://techcommunity.microsoft.com/blog/appsonazureblog/introducing-azure-durable-task-for-pydantic-ai-agents/4571024) · [Azure 技术文档](https://learn.microsoft.com/en-us/azure/durable-task/sdks/durable-task-for-ai-agents)

模型请求、函数工具与 MCP 调用可作为独立活动记录，恢复时复用已经记下的结果。工作流能暂停等待人工批准而无需让活动保持运行；中断发生在结果持久化前时，外部操作仍可能再次执行。官方明确持久执行不保证外部副作用恰好一次。

#### 4. AWS 展示在 Agentic Retrieve 中绑定会话与长期记忆

AWS Machine Learning Blog，Peng Yang 等｜文章发布：**2026-11-17 06:43:30**（11 月 16 日 22:43:30 UTC，官方订阅）｜首次发现：2026-11-17｜[工程原文](https://aws.amazon.com/blogs/machine-learning/build-memory-aware-ai-agents-with-agentic-retrieve-on-amazon-bedrock-managed-knowledge-base/)

示例用验证后的身份令牌派生用户记忆标识和知识库 ACL 上下文，不接受客户端直接指定这两个身份。一次流式调用可恢复会话历史、按需检索长期记忆，按 ACL 过滤文档，并返回带引用的答案和追踪事件；文章也区分了应用、知识库和 AgentCore Memory 各自负责的部分。
