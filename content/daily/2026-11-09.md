## 资讯详情

### Agent 开发

**1. OpenAI Agents SDK Python v0.24.0-alpha.7：应用可接管会话存储与恢复**

OpenAI｜预发布：**2026-11-08 15:05:11**（07:05:11 UTC）｜首次发现：2026-11-09｜[官方发布说明](https://github.com/openai/openai-agents-python/releases/tag/v0.24.0-alpha.7)

原生执行新增自定义持久存储，可保存根会话历史及自动 Python 工具的结果；状态未明的调用可交由应用核对，恢复时不会自动重放这些副作用。该存储暂不覆盖子 Agent、原生工具和可移植检查点。新版还把新执行环境的写入策略默认设为 strict，工作目录仍可写，额外目录需显式配置。对会修改外部系统的运维 Agent，这两项变化分别涉及故障恢复和写权限边界。

### Agent 治理

**2. LiteLLM v1.110.0-dev.2：可按密钥或团队停止留存提示词**

LiteLLM 项目｜开发版预发布：**2026-11-08 10:25:47**（02:25:47 UTC）｜首次发现：2026-11-09｜[官方发布说明](https://github.com/BerriAI/litellm/releases/tag/v1.110.0-dev.2)

费用日志新增按密钥或团队关闭提示词存储的设置。路由器修复了首次失败已记录后，后续重试与模型回退路径未完整记录的问题。两项变化分别影响网关留存的数据范围，以及排查一次请求实际经历了哪些路由步骤。

**3. 微软技术文章拆解非人类身份的三层防护**

Microsoft Community Hub；Randall Irwin｜文章发布：**2026-11-08（仅日期）**｜首次发现：2026-11-09｜[官方原文](https://techcommunity.microsoft.com/blog/healthcareandlifesciencesblog/securing-the-non-human-identity-attack-surface/4571497)

作者区分了三层控制：Entra Workload ID 在令牌签发时执行条件访问和风险控制；Defender for Resource Manager 分析服务主体在 Azure 管理面的操作，检测异常行为；Agent 365 提供 Agent 盘点、归属人及访问生命周期治理。这是一篇安全架构实践文章，文中列举的是现有能力。
