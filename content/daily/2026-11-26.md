### 二 Agent 开发

#### 1 Anthropic 用生产系统验证 Messages API 的 Rust 迁移

**机构：Anthropic Engineering。发布日期：2026-11-25，仅日期精度，时分／时区未取得。** [原文 Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)

**原文事实：**团队将 Python API 与 Rust API 的处理步骤对照，记录差异位置和长度等指纹而不读取用户请求正文；定期按指纹归并记录，由协调 Agent 分派修复。内层在隔离沙箱快速复现与检查，修复须经 PR 人工审查后进入外层生产影子流量验证，审查意见再写入共享记忆。团队自报迁移后每请求 CPU 用量约降70%、首 token 中位延迟约降20%；这些是该生产迁移的报告结果，不是通用模型基准。

**AIOps关联：**展示了从生产差异信号、去重分派到修复与运行效果回查的闭环。

#### 2 Cloudflare 发布 Search for Agents

**机构：Cloudflare；作者：Celso Martinho、Gabriel Massadas、Nelson Duarte。发布日期：2026-11-25，仅日期精度，时分／时区未取得。** [原文 Introducing Search for Agents](https://blog.cloudflare.com/search-for-agents/)

**原文事实：**为站点启用后，服务创建 AI Search 实例并抓取、索引内容，在本站域名下提供可发现的搜索端点。HTML 元数据和 Markdown front matter 可声明端点；接口支持 GET 与 HTTP QUERY，返回检索到的 Markdown 内容，而非另一个模型生成的答案。实例仍受站点 WAF、抓取控制等配置与 AI Search 用量限制约束。博客与同日 Changelog 合并为同一事件。

**AIOps关联：**可作为 Agent 检索公开技术文档的工具入口。

### 三 Agent 治理

#### 3 Cloudflare CLI 与 MCP 可直接激活云产品订阅

**机构：Cloudflare。发布日期：2026-11-25，仅日期精度，时分／时区未取得。** [原文 Activate Cloudflare subscriptions from the CLI and MCP](https://developers.cloudflare.com/changelog/post/2026-11-25-activate-pay-as-you-go-cli-mcp/)

**原文事实：**CLI 与 MCP 使用的 OAuth 会话新增订阅激活能力，覆盖 Workers Paid、R2 和 Zero Trust 等流程。CLI 需要更新并重新认证以取得新的 scopes，账户须满足已验证邮箱与付款资料条件。支持 elicitation 的 MCP 客户端会展示套餐价格，并在激活前请求用户许可；不支持该交互的客户端转到控制台。

**AIOps关联：**这是涉及云资源与费用副作用的工具调用，将运行权限和人工确认结合的官方产品例子。

### 四 平台工程与运维

#### 4 微软介绍 Brewlet 将批准的运行时作为 Kubernetes 基础设施

**机构：Microsoft Apps on Azure Blog；作者：Bruno Borges（Microsoft）。发布日期：2026-11-25；页面另标同日 Updated、Version 2.0，均未取得时分／时区。** [原文 Introducing Brewlet Manage Golden Images at Platform Speed](https://techcommunity.microsoft.com/blog/appsonazureblog/introducing-brewlet-manage-golden-images-at-platform-speed/4576767)

**原文事实：**Brewlet 是 MIT 许可的实验性开源项目。应用 OCI 镜像保存应用文件及启动描述，平台团队按 digest 批准 golden runtime，并决定供给的节点池；容器创建时组合二者，仍使用 containerd／runc。运行时轮换不是给运行中进程原地打补丁：旧容器保留启动时的版本，新容器使用新版本，启用相关功能且主动选择的工作负载通过控制器滚动替换。应用自行打包的依赖漏洞仍需应用更新。

**AIOps关联：**涉及集中运行时修补、启动授权和版本可见性。实验性发布不等同生产正式可用。

#### 5 Cloudflare D1 Insights 增加索引建议

**机构：Cloudflare。发布日期：2026-11-25，仅日期精度，时分／时区未取得。** [原文 D1 Insights index recommendations](https://developers.cloudflare.com/changelog/post/2026-11-25-d1-index-recommendations/)

**原文事实：**D1 Insights 可为数据库提供索引建议，每条包含 `CREATE INDEX` 语句、预计改善的查询及这些查询的使用指标。用户可在控制台、CLI 或 API 开关建议，并查看建议列表。该发布描述的是建议能力，没有说明会自动执行建索引。

**AIOps关联：**为数据库性能诊断与优化提供附带查询证据的操作建议。
