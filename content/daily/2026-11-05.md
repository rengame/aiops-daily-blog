### U Mobile 分享 AiDaH 电信运维 Agent 平台实践

AWS；Jin Tiong Lim、Colm Mulholland、Kelvin Kok｜发布日期：2026-11-04（仅日期精度）｜首次发现：2026-11-05｜[原文](https://aws.amazon.com/blogs/machine-learning/how-u-mobile-built-agentic-telco-operations-with-amazon-bedrock-agentcore/)

## Agent 开发

### Deep Insight 用四层上下文工程支撑长任务

AWS；Yoonseo Kim 等｜发布日期：2026-11-04（仅日期精度）｜首次发现：2026-11-05｜[原文](https://aws.amazon.com/blogs/machine-learning/four-layers-of-context-engineering-for-production-ai-agents-how-deep-insight-applies-them-in-working-code/)

参考实现将上下文隔离、输出预算、文件外置和独立校验分层组合。专业 Agent 只向编排者回传摘要，代码与详细结果保存为文件，技能按需加载，校验与只读审计角色检查数值和引用。文中 Token 节省比例来自该实现，不能直接当作普遍收益。

## 平台工程与运维

### HiCache 介绍跨并行拓扑的 KV 缓存复用

ApsaraDB；Zhangheng Huang、Shunkang Zhang 等｜发布日期：2026-11-04（仅日期精度）｜首次发现：2026-11-05｜[原文](https://www.alibabacloud.com/blog/hicache-across-multi%E2%80%91parallelism-and-distributed-serving_603726)

文章解释 CP 分片、PP 异步传输一致性、推测解码状态恢复，以及预填充／解码分离下的前缀复用。重点是保持各 rank 对缓存前缀和完成事件的共同判断。统一布局要求兼容的模型、数据类型与页布局，部分路径需集成版本；这是工程实践，非所有部署均已支持的承诺。

### OpenAI 披露 Linux 内核自动化安全研究流水线

OpenAI｜发布日期：2026-11-04（仅日期精度）｜首次发现：2026-11-05｜[原文](https://openai.com/index/a-thousand-fewer-paths-to-root/)

原型在隔离环境中依次发现候选问题、动态复现、评估可利用性并生成候选补丁，最后由研究人员审核报告。文中区分 2,308 个候选、1,724 个动态复现与 948 个去重本地提权案例；结果不代表全部补丁已合入，也不代表普通部署均受影响。

### Apigee Operator for Kubernetes 1.1.2 发布安全更新

Google Cloud｜发布日期：2026-11-04（仅日期精度）｜首次发现：2026-11-05｜[原文](https://docs.cloud.google.com/release-notes/#November_04_2026)

官方发布记录宣布 Operator 1.1.2 可用，包含 Netty、Jackson、Jetty、Vert.x 和 Guava 的安全修复。记录列明 Netty 升至 4.1.137.Final、Jackson 至 2.21.7、Jetty 至 12.0.36。此条面向网关及 Kubernetes 控制组件维护，不等同于 Agent 功能发布。
