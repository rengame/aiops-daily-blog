### Agent 开发

**2. AWS UAEF 用统一轨迹对比不同版本的 Agent**

AWS Machine Learning Blog｜文章发布：**2026-11-11 23:50:55**（11 月 11 日 15:50:55 UTC，官方订阅记录）｜首次发现：2026-11-12｜[官方原文](https://aws.amazon.com/blogs/machine-learning/uaef-a-framework-agnostic-system-for-closed-loop-evaluation-of-ai-agents/)

适配器把消息、工具调用和 Agent 间交接转成统一轨迹，框架可按七个维度的 36 个内置指标进行打分，并把实验结果与基线比较。工具评估覆盖选择、顺序和参数；轨迹在存储前可检查个人信息。AWS 特别区分评估信号与运行时安全控制，评审模型分数不承担授权决策。

**3. 阿里云介绍 AgentScope 2.0 的长任务 Harness**

阿里云原生社区｜文章发布：**2026-11-11（仅日期）**｜首次发现：2026-11-12｜[官方原文](https://www.alibabacloud.com/blog/from-agent-framework-to-agent-harness-a-new-positioning-for-the-open-source-agentscope-project_603759)

文章用依赖漏洞排查举例，说明 Harness 如何保存任务与计划状态、把过大的工具输出卸载到工作区、压缩历史，并让子 Agent 在受限上下文中并行调查。作者将计划批准和执行权限分开：批准只改变工作阶段，生产发布仍需独立权限，父任务的只读状态也不会自动约束所有执行器。本条是工程设计文章，未把发文日当成版本发布日期。

**4. LangChain 1.5.0 加入 Beta 模型路由中间件**

LangChain 项目｜版本发布：**2026-11-11 23:47:22**（15:47:22 UTC）｜首次发现：2026-11-12｜[官方发布说明](https://github.com/langchain-ai/langchain/releases/tag/langchain%3D%3D1.5.0)

版本新增模型路由及自动模式中间件，`ModelRouterMiddleware` 明确标为 Beta。主包最低 Python 版本提高至 3.11，最低 `langchain-core` 为 1.8.0；Python 3.10 环境仍解析到 1.4.x。

### Agent 治理

**5. Google Agent Gateway 跨云治理进入有限预览**

Google Cloud｜发布记录：**2026-11-11（仅日期）**｜首次发现：2026-11-12｜[官方发布记录](https://docs.cloud.google.com/gemini-enterprise-agent-platform/release-notes) · [架构文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/agents/governance/agent-gateway-cross-cloud/overview)

Agent 继续运行在 EKS、AKS、OpenShift 或其他符合 CNCF 规范的 Kubernetes 集群中。Google 托管集中管理面，集群内控制器同步注册与配置，命名空间内的 Envoy 代理执行访问和 Model Armor 策略，并把日志和链路送入 Cloud Logging、Cloud Trace。治理范围包括 LLM、MCP 和 A2A 流量；需要申请预览。

**6. AWS 分享 MCP 工具变更如何自动同步到 Agent Registry**

AWS Machine Learning Blog｜文章发布：**2026-11-12 04:52:48**（11 月 11 日 20:52:48 UTC，官方订阅记录）｜首次发现：2026-11-12｜[官方原文](https://aws.amazon.com/blogs/machine-learning/automating-aws-agent-registry-updates-with-push-based-architecture/)

CloudTrail 捕捉 `UpdateAgentRuntime`，EventBridge 将事件路由到同步 Lambda。Lambda 使用 AgentCore Identity 获取 OAuth 令牌，调用 MCP 的 `initialize` 和 `tools/list`，比较工具定义并更新有变化的目录记录。示例支持跨账号，也可在单账号内运行；它只更新已经登记的服务器。

**7. LiteLLM 1.109.0 支持流中途回退，调整限流与回退配置**

LiteLLM 项目｜版本发布：**2026-11-11 08:56:51**（00:56:51 UTC）｜首次发现：2026-11-12｜[官方发布说明](https://github.com/BerriAI/litellm/releases/tag/v1.109.0)

流式回答中断后，可交给配置的备用模型继续。版本要求用模型名称列表表示回退目标；要维持部署级硬性 RPM 上限，需显式启用 `enforce_model_rate_limits` 预调用检查。本条聚焦 1.109.0 的路由变化，不重复上一期已收录的 LTS 计费与身份修复及其回移。

### 平台工程与运维

**8. GKE 容量缓冲正式可用**

Google Cloud｜发布记录：**2026-11-11（仅日期）**｜首次发现：2026-11-12｜[GKE 官方发布记录](https://docs.cloud.google.com/kubernetes-engine/docs/release-notes)

GKE Standard 和 Autopilot 从 1.37.1-gke.3020000 起可通过 `CapacityBuffer` 预置计算容量。主动与待机两种缓冲均正式可用，待机容量可选择暂停，用于在负载增长前预留扩容资源。这是扩容能力，不代表所有版本和集群已启用。

**9. AWS Emulator 支持在本机和 CI 中隔离验证 AWS API 调用**

AWS What's New｜发布：**2026-11-12 01:00:00**（11 月 11 日 17:00:00 UTC，官方订阅记录）｜首次发现：2026-11-12｜[官方公告](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-emulator-now-available/)

可用现有 AWS CLI 和 SDK 对模拟端点运行测试，无需部署 AWS 资源。每个实例使用独立端口、密钥和内存状态，适合隔离 Agent 与 CI 的测试资源。未实现操作返回 501，具体覆盖和响应一致性以官方保真度报告为准。

**10. Cloudflare 解释 Meerkat 为何选择 QuePaxa**

Cloudflare；João Pedro Leite、Bob Halley、James Larisch｜文章发布：**2026-11-11 22:24:46**（14:24:46 UTC，官方订阅记录）｜首次发现：2026-11-12｜[官方原文](https://blog.cloudflare.com/choosing-quepaxa/)

Cloudflare 为内部全球控制面试验 Meerkat。文章解释，跨洲链路的延迟波动和局部故障可能拖慢单领导者协议，误判又可能触发反复选举；团队因此选择无需依赖固定领导者即可推进的 QuePaxa。本条是工程选型披露，Meerkat 仍是实验性服务。
