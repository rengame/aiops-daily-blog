## 资讯详情

### AIOps 应用

**1. OpenAI Performance Factory 用 Agent 持续处理性能回归**

OpenAI / Okay Zed、Cyrus Forbes｜发布：**2026-11-19 16:00:00（北京时间）**｜首次发现：2026-11-20｜[原文](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast)

性能告警触发任务后，Agent 查代码与遥测、记录根因并提交修复建议；工程师决定是否上线，上线后由 Agent 再核对恢复。任务状态独立于单次会话，等待评审或部署时通过事件订阅恢复工作。OpenAI 报告运行三个多月后记录逾 1,700 次调查、定位逾 600 个案例；这是内部生产实践数据，不代表任意系统都能取得相同效果。

**2. SageMaker 检查推理端点的延迟漂移与容量浪费**

AWS Machine Learning Blog / Hazim Qudah 等｜发布：**2026-11-20 05:28:18（北京时间）**｜首次发现：2026-11-20｜[原文](https://aws.amazon.com/blogs/machine-learning/amazon-sagemaker-ai-now-detects-latency-drift-idle-gpus-and-missed-optimizations-on-your-inference-endpoints/)

对使用 vLLM 服务容器和 GPU 实例的合格端点，默认监控延迟、GPU 利用率及服务配置，不读取请求与响应内容。发现延迟漂移、闲置资源或配置优化空间后通过 AWS Health 提示，用户可转到 Studio 在独立计算资源上比较替代配置；生产端点不会自动变更。监控本身不增加 GPU 成本，基准作业仍按标准费用收费。同事件的 What's New 公告合并到本条。

**3. Grafana Notebooks 把图表、查询与 Assistant 调查结果汇成文档**

Grafana Labs / Daniel Moosdeen Mui｜发布：**2026-11-19 23:22:49（北京时间）**｜首次发现：2026-11-20｜[原文](https://grafana.com/blog/bring-charts-queries-and-context-into-one-shareable-document-introducing-grafana-notebooks/)

Notebooks 可从 Dashboard、Explore 或 Assistant 会话加入可视化，编排证据与说明，并固定时间范围供同事查看。Notebook 内可调整查询而不修改来源 Dashboard。原文说明该能力随 Grafana 13.3 进入公开预览，Cloud 访问会在随后数周逐步开放，自托管版需要功能开关；评论与实时编辑仍在探索中，不能当作已发布功能。

**5. AppConfig 将模型调用设置和提示词独立纳入安全发布**

### 平台工程与运维

**7. Lambda Durable 用 OpenTelemetry 连接跨调用、等待和恢复**

AWS / Ricardo Marques、Daniel Abib、Nicolas Tarzia｜同事件功能公告：**2026-11-20 04:00:00（北京时间，官方 RSS）**｜首次发现：2026-11-20｜[功能公告](https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-otel/) · [官方工程原文](https://aws.amazon.com/blogs/compute/aws-lambda-durable-functions-observability-with-opentelemetry/)

Python OTel 插件为同一 durable execution 生成确定性 trace ID，为步骤、等待及回调创建 span，并把 trace/span ID 加到日志，减少恢复执行时的链路碎片。工程文章区分 execution 与 invocation 两种视图；长工作流仍受后端 span 接收时间窗限制，不能因为使用 invocation 视图就保证最终 Workflow span 被接收。
