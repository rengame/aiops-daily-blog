### AIOps 应用

#### 1. Grafana Pyroscope：排障 Agent 可查询持续剖析数据

Grafana Labs，Tiffany Jernigan｜文章发布：**2026-11-14 01:14:29**（11 月 13 日 17:14:29 UTC，官方订阅）｜首次发现：2026-11-14｜[工程原文](https://grafana.com/blog/whats-new-in-pyroscope-profile-more-of-your-workflows-troubleshoot-with-ai-agents-and-more/?pg=blog)

`gcx profiles` 可按 CPU 等资源用量列出优先调查的服务，再用 exemplars 定位异常实例的单次 profile，查询热点函数或导出 pprof。文章还介绍了 Python、Rust 的内存剖析及 Windows 上的 .NET 剖析。此处的日期是工程文章发布时间，文章汇总的能力不一定同日上线。

### Agent 开发

#### 2. Codex 0.169.0 修复非交互 MCP 信任与中断处理

OpenAI Codex｜版本发布：**2026-11-13 16:37:05**（08:37:05 UTC，GitHub Releases API）｜首次发现：2026-11-14｜[官方发布说明](https://github.com/openai/codex/releases/tag/rust-v0.169.0)

在未信任的目录执行 `codex exec` 时，即使启用了工作区写权限，项目配置和 MCP 服务仍保持禁用，需显式信任项目。该版本也修复了延迟到达的中止或审批取消信号误伤后续轮次的问题，并记录了 app-server 客户端如何为指定模型供应商查询模型或授权网关。

#### 3. langchain-openai 1.8.0 接入 Decisions API，并调整 Python 兼容范围

LangChain 项目｜版本发布：**2026-11-14 00:48:27**（11 月 13 日 16:48:27 UTC，GitHub Releases API）｜首次发现：2026-11-14｜[官方发布说明](https://github.com/langchain-ai/langchain/releases/tag/langchain-openai%3D%3D1.8.0)

集成包新增 `OpenAIClassifier`，接入用于分类和评分的 Decisions API。该集成包最低要求 Python 3.11 和 langchain-core 1.8.0，Python 3.10 环境仍解析到 1.7.x；这是独立于前期 LangChain 主包更新的发布。

### Agent 治理

#### 4. LiteLLM 1.108.8 LTS 修复 MCP 重复登录和文件归属检查

LiteLLM 项目｜版本发布：**2026-11-14 04:21:21**（11 月 13 日 20:21:21 UTC，GitHub Releases API）｜首次发现：2026-11-14｜[官方发布说明](https://github.com/BerriAI/litellm/releases/tag/v1.108.8)

当 MCP 服务用细粒度 scope 回应 `mcp_all` 时，旧版本可能反复要求登录并以 `Authentication incomplete` 结束；本次 LTS 补丁修复该问题。发布还修复了 Gemini 文件 ID 的替代表达未纳入归属检查的问题。

#### 5. AWS Secrets Manager 支持同区域跨账户复制凭证

AWS｜公告发布：**2026-11-13 16:00:00**（08:00:00 UTC，官方订阅）｜首次发现：2026-11-14｜[公告链接](https://aws.amazon.com/about-aws/whats-new/2026/11/secrets-manager-cross-account/) · [官方用户指南](https://docs.aws.amazon.com/secretsmanager/latest/userguide/cross-account-replicate-secrets.html) · [授权文档](https://docs.aws.amazon.com/secretsmanager/latest/userguide/cross-account-replicate-permissions.html)

目标账户先创建副本并配置权限，源账户再关联并启动异步复制。主副本须在同一区域，每个主凭证最多一个跨账户副本，且副本需要客户管理的 KMS 密钥。发布时间来自官方订阅，功能由公开产品文档核实。

### 平台工程与运维

#### 6. Cloudflare Spend Management 测试版可按产品告警或暂停使用

Cloudflare｜工程公告发布：**2026-11-13 22:00:00**（14:00:00 UTC，原文发布元数据）｜首次发现：2026-11-14｜[工程原文](https://blog.cloudflare.com/spend-management/) · [官方配置文档](https://developers.cloudflare.com/billing/manage/spend-management/)

按量付费账户可为 Workers 和 Durable Objects 分别设置账期内的费用阈值，可仅发送通知，也可在达到限额时暂停支持的用量操作。计费与阻断存在延迟，记录金额仍可能超出设定值。该机制管理运行成本，可与 AI Gateway 已有的按用户、模型预算配合。
