#### 2. DeepSeek Harness 接入 OpenTelemetry 的两种方式

阿里云原生社区｜文章发布：**2026-11-12（仅日期）**｜首次发现：2026-11-13｜[官方工程原文](https://www.alibabacloud.com/blog/deepseek-harness-a-practical-guide-to-comprehensive-observability_603771)

原文展示两条采集路径：LoongSuite Pilot 由后台进程采集并归一化不同 Agent 的本地事件；Harness 内的插件则直接发出 OpenTelemetry GenAI 追踪与指标，可按模型调用尝试记录 span，默认不采集内容。作者指出，两条路径同时向同一后端、同一服务标识上报时，可能重复计量。

### Agent 开发

#### 3. AWS 分享跨账户的 A2A 编排示例

AWS Machine Learning Blog，Amit Chaudhary｜文章发布：**2026-11-12 23:42:21**（15:42:21 UTC，官方订阅记录）｜首次发现：2026-11-13｜[官方原文](https://aws.amazon.com/blogs/machine-learning/build-composable-interoperable-multi-agent-systems-with-a2a-on-aws/)

示例以 LangChain 编排器发现 Strands 构建的服务端 Agent，通过 Agent Card 获知能力；两个 AWS 账户分别管理 Cognito，通过 OAuth 认证双向调用，避免双方共享客户端密钥。原文是可组合多 Agent 的实现示例。

#### 4. Cloudflare 开源实验性浏览器引擎 Kitesurf

Cloudflare｜发布记录：**2026-11-12（仅日期）**｜首次发现：2026-11-13｜[官方更新记录](https://developers.cloudflare.com/changelog/post/2026-11-12-kitesurf-open-source/)

Kitesurf 可在 Workers 中执行 JavaScript、渲染网页并截屏，无需为每次操作启动浏览器容器；可用 CDP 客户端连接。发布说明将它定位为实验项目，并明确自部署实例没有内建认证。这为检查页面状态的 Agent 提供了一个轻量的浏览器工具选项。

### Agent 治理

#### 5. 阿里云沙箱实验发现 VPC DNS 可绕过 HTTP 出口约束

阿里云国际技术社区，Hosung Kim｜文章发布：**2026-11-12（仅日期）**｜首次发现：2026-11-13｜[工程实践原文](https://www.alibabacloud.com/blog/locking-down-ai-agent-sandbox-with-alibaba-cloud-ai-gateway_603772)

作者把 AgentRun 沙箱的模型调用限制到私有 AI Gateway，模型凭证留在网关。测试中，直接出网已封闭，VPC DNS 仍能转发携带假密钥的域名。移除对 VPC 解析器的放行规则后，沙箱改用固定私网 IP 访问网关。文章披露的是该实验环境的结果，未采集攻击者一侧的 DNS 接收日志。

#### 6. Google Cloud API Keys 远程 MCP 服务正式可用

Google Cloud｜正式可用记录：**2026-11-12（仅日期）**｜首次发现：2026-11-13｜[官方发布记录](https://docs.cloud.google.com/release-notes/) · [使用文档](https://docs.cloud.google.com/api-keys/docs/use-api-keys-mcp) · [工具参考](https://docs.cloud.google.com/api-keys/docs/reference/mcp)

远程 MCP 服务器让 AI 应用通过工具创建、查看、限制和管理 Google Cloud 项目的 API 密钥。启用 MCP 端点与调用者对密钥资源的访问是两个权限环节；工具仍受调用身份的 IAM 权限约束。

### 平台工程与运维

#### 7. GKE Agent Sandbox 正式可用，Agent Gateway 进入 Rapid 预览

Google Cloud｜发布记录：**2026-11-12（仅日期）**｜首次发现：2026-11-13｜[GKE 官方发布记录](https://docs.cloud.google.com/kubernetes-engine/docs/release-notes#November_12_2026) · [Agent Platform 发布记录](https://docs.cloud.google.com/gemini-enterprise-agent-platform/release-notes)

Agent Sandbox 可安装在任一受支持的 GKE 版本上，面向需要隔离、单副本且有状态的工作负载。Agent Gateway for GKE 集中管理流入、流出及 Agent 之间的流量；此次预览要求 Rapid 渠道上运行 `1.37.2-gke.1042000` 或更高版本，限 `europe-west1` 和 `us-central1`。这是 GKE 内的预览，与上期的跨云有限预览分别发布。

#### 8. 下一代 AgentCore Runtime 成为新建运行时的默认选项

AWS｜公告发布：**2026-11-12 13:00:00**（05:00:00 UTC，官方订阅记录）｜首次发现：2026-11-13｜[官方公告](https://aws.amazon.com/about-aws/whats-new/2026/11/new-agentcore-runtime-default/) · [工程原文](https://aws.amazon.com/blogs/machine-learning/run-agents-securely-and-efficiently-with-the-next-generation-agentcore-runtime/)

公告覆盖列出的 AWS 区域和新建运行时。新一代运行时按会话提供 Firecracker 微型虚拟机，从已初始化的 Agent 快照启动，可在空闲时缩减至零；资源上限为 8 vCPU、32 GB 内存和 10 GB 容器镜像。公告未表示现有运行时自动切换。

#### 9. Anthropic 发布自托管 Claude Managed Agents

Anthropic｜发布记录：**2026-11-12（仅日期）**｜首次发现：2026-11-13｜[Claude Platform 发布记录](https://platform.claude.com/docs/en/release-notes/overview) · [自托管文档](https://platform.claude.com/docs/en/managed-agents/self-hosted)

用户可以在自己的基础设施上运行 Managed Agents 服务，保存 Agent、会话和历史，并自行托管工具执行环境。模型请求仍发送到选定的供应商，默认是 Anthropic；发布记录要求联系账户团队申请使用。
