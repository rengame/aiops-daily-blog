**1. Google Database Center 预览数据库变更自动评估**

Google Cloud / Isabella Lubin、Apoorv Shrivastava｜发布时间：**2026-11-19 01:00:00（北京时间）**｜首次发现：2026-11-19｜[原文](https://cloud.google.com/blog/products/databases/database-center-assessments-for-cloud-sql-for-postgresql/)

面向 Cloud SQL for PostgreSQL 的 assessments 工作流会克隆实例、建立合成负载基线、在克隆环境应用建议，再比较吞吐、平均延迟、CPU 和内存，完成后删除临时克隆。用户可用自然语言调整连接数、事务数和运行时长。预览支持机器规格升级、Enterprise 到 Enterprise Plus 升级，以及 Enterprise Plus 数据缓存评估；它提供隔离评估，不代表自动修改生产库。

### Agent 开发

**2. Airbnb 用任务成本与运行信号管理编码 Agent**

AWS Machine Learning Blog / Airbnb 与 AWS，Alan Yao 等｜发布时间：**2026-11-19 05:48:19（北京时间）**｜首次发现：2026-11-19｜[原文](https://aws.amazon.com/blogs/machine-learning/how-airbnb-uses-cost-per-task-to-operate-coding-agents-on-amazon-bedrock/)

Airbnb 对固定任务集同时记录完成质量和整项任务的 token 成本，用结果选择默认模型与推理强度上限，再用网关汇总和 CloudWatch 检查生产差异。文章将首 token 等待、输出长度和生成速度分开，避免把回答变长误判为模型变慢；成本统计包括缓存读写和低分尝试。这是企业工程实践，不是模型能力排名。

### Agent 治理

**3. AWS 分享 AI 资产盘点、合规控制与异常监测的组织级实践**

AWS Cloud Operations Blog / Matej Macek 等｜发布时间：**2026-11-19 02:33:55（北京时间）**｜首次发现：2026-11-19｜[原文](https://aws.amazon.com/blogs/mt/governing-your-ai-workloads-on-aws-at-scale-visibility-controls-and-monitoring/)

文章用 Security Hub、Config、CloudTrail 等组合识别托管、自托管及外部 AI 使用，再按工作负载部署四类 Config 合规包。合规变化可经 EventBridge 送到责任团队或既有修复流程，工具调用频率异常由 CloudWatch 观测。AWS 明确指出不存在单一完整盘点源，部分 AgentCore 设置仍需自定义规则；这是治理方法文章，非全部能力当天上线。

**4. Google Cloud 详解 Envoy 的模型、token 与 MCP 流量治理**

Google Cloud / Abhi Maras、Boteng Yao｜发布时间：**2026-11-19 01:00:00（北京时间）**｜首次发现：2026-11-19｜[原文](https://cloud.google.com/blog/products/networking/the-envoy-agentic-stack-routing-models-tokens-and-mcp/)

文章把请求正文解析、token 预算、模型与工具路由以及外部安全检查组合成 Agent 网络治理层：按租户、项目或模型计算 token 配额，利用 EPP 与缓存亲和性选模型后端，并通过外部处理接口接入安全策略。作者以“Layer 8/9”描述 Agent 协议和框架层，这是文章的架构表述；内容涉及 Envoy 生态多项能力，并非单一版本的统一正式发布。

**5. AgentCore Identity 支持私有 CA 信任的内部身份提供方**

AWS Machine Learning Blog / Aastha Paul、Swara Gandhi｜发布时间：**2026-11-19 04:53:41（北京时间）**｜首次发现：2026-11-19｜[原文](https://aws.amazon.com/blogs/machine-learning/private-certificate-authority-support-in-amazon-bedrock-agentcore-identity/)

AgentCore Identity 可读取 Secrets Manager 或 S3 中的 PEM 格式根／中间 CA 公共证书，通过 VPC Lattice 连接内部 IdP，并验证发现、JWKS 和令牌端点的服务端证书。文章说明证书仅在创建或更新凭证提供方时读取；更换存储内容后仍需更新提供方，续期指标可在 CloudWatch 观察。示例使用 Keycloak 和 AWS Private CA。

**6. AgentCore Gateway 接入私有 API 与 MCP 的集中检查架构**

AWS Machine Learning Blog / Puneeth Komaragiri 等｜发布时间：**2026-11-19 03:05:45（北京时间）**｜首次发现：2026-11-19｜[原文](https://aws.amazon.com/blogs/machine-learning/connect-amazon-bedrock-agentcore-gateway-to-private-apis-in-a-hub-and-spoke-network-with-centralized-inspection/)

AWS 给出网络团队拥有子网、跨 VPC 流量必须双向经过防火墙的 hub-and-spoke 示例：由网络账户持有 VPC Lattice resource gateway，经 Transit Gateway 到检查 VPC，再共享后端资源配置。原文区分这种约束与普通托管／自管接入，提供部署与验证资料；证据来自 us-east-1、三个成员账户及一个管理账户的实验环境。

**7. OpenAI 公开 Codex 沙箱设计与权限边界**

OpenAI / Michael Bolin｜发布时间：**2026-11-18 16:00:00（北京时间）**｜首次发现：2026-11-19｜[原文](https://openai.com/index/inside-the-codex-sandbox)

Codex 在用户现有开发环境中使用操作系统隔离机制限制命令，子进程继承限制。文章解释文件权限配置、受控网络代理与审批的衔接，并给出把 MCP 服务置于沙箱的示例。Linux 使用 bubblewrap 与 seccomp-bpf，macOS 使用 Seatbelt；默认工作区配置允许较广读取，但限制写入和网络，沙箱不是消除所有宿主机风险的保证。这是实现解读，不是本期新发布的独立沙箱产品。

### 平台工程与运维

**8. Kyverno CEL 准入优化：每个请求只转换一次对象**

CNCF / Nirmata，Raunak Madan｜发布时间：**2026-11-18 20:30:00（北京时间）**｜首次发现：2026-11-19｜[原文](https://www.cncf.io/blog/2026/11/18/optimizing-kubernetes-admission-control-where-kyvernos-cel-admission-cost-actually-goes/)

作者剖析发现，CEL 策略引擎大量分配来自每条匹配策略重复把同一 AdmissionRequest 转成 map。优化将转换移到循环前复用，同时保留各引擎原有的策略语义，文中称修复随 1.19.2 交付。约 50 KB Pod、16 条策略的引擎内基准从 4.91 ms 降为 0.16 ms；该数值不含 webhook、API server 或 etcd，不代表端到端生产准入延迟。
