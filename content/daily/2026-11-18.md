**6. Grafana 解释 Loki 的二级索引如何加速日志排查**

Grafana Labs｜北京时间 11-18 00:53:32（官方博客 RSS）｜首次发现：11-18｜[原文](https://grafana.com/blog/find-the-log-line-that-matters-faster-with-full-text-search-in-grafana-cloud-logs/?pg=blog)

Grafana Cloud Logs 用二级索引定位可能包含目标字符串的数据块，减少按请求 ID、交易 ID 或罕见错误扫过的日志。它保留原有标签和 LogQL，适用于文中列出的字面匹配、部分正则和结构化元数据过滤；复杂正则并非都能加速。这是对已正式可用能力的新技术解读。

**7. CNCF 大使分享如何识别 OpenTelemetry Collector 的性能开销**

作者用 Telemetrygen 的合成负载演示批处理、过多资源属性、采样和其他 Collector 配置如何影响 CPU、内存和导出。尾部采样可保留异常链路，但需要在作出决定前缓存链路；过载时背压和内存保护也可能丢弃遥测。文章是工程经验分享，未给出通用的性能提升幅度。

资源优化功能根据实际用量推荐 CPU 和内存请求。集群策略默认只给建议；切到 Apply 可在不重建 Pod 的情况下调整请求。预览限 EKS Auto Mode、Kubernetes 1.36 或更新版本及公告所列区域；可排除已由 Vertical Pod Autoscaler 管理的工作负载。

### AgentCore Memory 自动生成完整会话摘要

AWS What's New｜发布时间：北京时间 **11 月 18 日 03:17:00**（11 月 17 日 19:17:00 UTC，官方订阅发布字段；公告索引显示日期为 11 月 17 日）｜[官方公告](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-bedrock-agentcore-memory-full-session-summaries/) · [Summary strategy 文档](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/summary-strategy.html)

启用摘要策略的 Memory 会自动维护一条随新事件更新的完整会话摘要，既有已总结会话也适用，无需额外设置。它与分段摘要并存，以长期记忆记录保存，可按 FULL_SESSION 类型筛选读取。官方文档同时说明：完整摘要与同一 Memory 中其他记录使用相同 IAM 权限，类型过滤不构成独立授权边界。

### AgentCore Memory 将短期事件保留上限延长至十年

AWS What's New｜发布时间：北京时间 **11 月 18 日 03:22:00**（11 月 17 日 19:22:00 UTC，官方订阅发布字段；公告索引显示日期为 11 月 17 日）｜[官方公告](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-bedrock-agentcore-memory-10-year-retention/)
