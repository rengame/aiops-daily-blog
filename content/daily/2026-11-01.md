[官方发布记录](https://docs.cloud.google.com/release-notes/#October_30_2026) · [原文说明 Cross-project boundaries](https://docs.cloud.google.com/agent-registry/boundaries-and-topology)

Agent Registry 可通过中央 management project 汇总多个 member projects 中的 Agent、MCP 服务和工具，集中发现、搜索与治理。边界可定义在组织或文件夹上，并按 Resource Manager 标签筛选成员项目；成员项目继续运行各自的 Agent Runtime、Cloud Run 或 GKE 资源。自动发现的资源可以汇总，手动注册资源则受注册所在项目影响，不能理解为全部资源都会自动跨项目可见。该能力与运维 Agent 资产发现及管理范围有关。
