文章以结账接口 P99 告警为例，依次核对规则、指标、调用链、实体依赖与 Grafana 查询，将问题缩小到下游支付调用。CMS MCP 提供远程工具发现，仍由 RAM 控制读写权限；读取诊断数据与变更告警规则需要不同权限。标题所述耗时是文章场景，不能外推为服务指标。

### Azure SRE Agent 演示云账单变动调查

Microsoft Apps on Azure｜发布日期：正文与页尾均为 2026-11-02；官方 RSS 标注 2026-11-03 03:51:16 UTC，不能据此确定首次发布落入窗口。｜首次发现：2026-11-03（脚本记录，北京时间）｜[原文](https://techcommunity.microsoft.com/blog/appsonazureblog/why-did-our-azure-bill-change-investigating-cloud-spend-with-azure-sre-agent/4569760)

这是定制 FinOps 原型：用 Cost Management 取账单数据、Resource Graph 补资源信息、Advisor 提供优化建议，生成交互式报告。作者区分新增计费与新建资源、成本贡献与根因；报告显示最近刷新快照，定时刷新和告警需另行配置。

## Agent 开发

### Google Cloud 用对照实验评估 Agent Skills

### AgentScope 介绍 JEV 接入完整 Harness 的决策链路

Alibaba Cloud Native Community｜发布日期：2026-11-03（页面仅给日期）｜首次发现：2026-11-04（北京时间）｜[原文](https://www.alibabacloud.com/blog/teaching-agents-to-decide-from-jev-integration-to-the-full-harness-decision-flow_603722)

文章区分工具候选选择、执行前检查、上下文压缩和记忆准入。候选工具进入目录不代表获准执行；强制模式可阻止拒绝的调用，业务权限、参数校验和幂等仍由原执行链负责。记忆准入给出建议，实际写入由应用决定。

### Qwen Memory Agent 把持久记忆做成可检查的工具

Ryan Duffy；Alibaba Cloud Project Hub｜发布日期：2026-11-03（文章页面仅给日期；未将其作为仓库首次发布日）｜首次发现：2026-11-04（北京时间）｜[原文](https://www.alibabacloud.com/blog/qwen-memory-agent-treating-memory-as-a-measurable-engineering-problem_603719)

项目通过 HTTP 和 MCP 暴露记忆工具，记录事实类型与向量，支持替换过时事实，并按 Token 预算检索。归并建议需人工批准。作者报告合成离线数据上召回良好，但另一个十场景在线评估任务成功率仅 60%；两种指标不宜互换。

## Agent 治理

### AgentCore Gateway 调用 ServiceNow 时保留发起用户身份

AWS；Greg Biegel 等｜发布日期：2026-11-03；官方发布元数据 16:47:40 UTC（北京时间 11 月 4 日 00:47:40）｜首次发现：2026-11-04（北京时间）｜[原文](https://aws.amazon.com/blogs/machine-learning/servicenow-on-behalf-of-token-exchange-with-bedrock-agentcore-gateway/)

AWS 演示在网关目标配置 Microsoft Entra ID 的 OBO 令牌交换：每次请求将入站 JWT 换成受众面向 ServiceNow 的令牌，同时保留用户身份，后者按映射用户执行授权。文章注明原生方案要求 MCP 2025-11-25，不再需要自建 Lambda 交换拦截器。
