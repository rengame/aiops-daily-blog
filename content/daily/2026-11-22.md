## 资讯详情

### AIOps 应用

**1. CloudWatch Omni 接入 Microsoft Azure 平台日志、指标和追踪**

AWS｜发布：**2026-11-21 09:10（北京时间，官方订阅 published 字段；网页确认 Nov 21）**｜首次发现：**2026-11-22**｜[原文](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-omni-microsoft-azure)

官方公告确认，可采集 Azure resource logs、Azure Monitor platform metrics、VNet flow logs 及 Application Insights traces，与 AWS 遥测集中显示。连接 Microsoft Entra ID tenant 与 AWS 账户及区域后，可按订阅、Azure 区域、资源类型、标签及遥测类型选择采集范围；支持控制台和 AWS CLI 配置。公告说明覆盖所有 Azure Public Regions，数据可进入已提供 CloudWatch Omni 的区域。对跨云故障调查的直接价值是把 Azure 服务和 AWS 依赖放在同一观测入口。

### Agent 开发

**2. AWS Quick 用插件组合分发 Agent、Skill、连接器与工作流**

AWS｜发布：**2026-11-21 10:58（北京时间，官方订阅 published 字段；网页确认 Nov 21）**｜首次发现：**2026-11-22**｜[原文](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-quick-plugins-bundle-agents-skills-connectors-flows/)

插件将特定任务需要的 agents、skills、connectors、flows 打包为一次安装的组合，减少逐项配置。构建者也可在聊天中描述任务，由 Quick 组装自定义插件，再分享给团队、部门或组织。公告称该能力已在 Quick 可用的全部区域提供。与运维 Agent 的关联在于诊断知识、系统连接与流程能够组合分发；公告展示的是通用工作场景，未提供运维效果实测。

**3. Bedrock Web Search 扩展语言支持与国家偏向搜索**

AWS｜发布：**2026-11-21 08:17（北京时间，官方订阅 published 字段；网页确认 Nov 21）**｜首次发现：**2026-11-22**｜[原文](https://aws.amazon.com/about-aws/whats-new/2026/11/web-search-amazon-bedrock/)

面向 Bedrock AgentCore 与 Bedrock 的 Web Search 新增西班牙语、法语、德语、意大利语、日语及非美式英语。可选 country 字段接受 ISO 3166-1 alpha-2 代码，使结果偏向指定国家的来源；它是搜索相关性参数。原文说明查询在调用区域处理，已有客户自动获得语言能力，同一语言与其他语言定价一致。多地区运维 Agent 检索区域公告和本地技术资料时可参考此项工具更新。
