### 4 阿里云介绍面向 Agent 的数据库安全边界

发布机构：Alibaba Cloud Community。发布日期：2026-10-30，仅日期精度。首次发现：2026-10-31。

[原文：Your Database's Biggest User Is Now an Agent — and That Changes Security](https://www.alibabacloud.com/blog/your-databases-biggest-user-is-now-an-agent-%E2%80%94-and-that-changes-security_603709)

文章区分连接身份、Agent 行为和数据库访问审计：Agent Data Gateway 为 Agent 分配身份与 token，管理数据库、表、列及行级权限，并将数据库凭证保留在网关内；DataGuard for Agent 检查输入、工具调用、输出与会话，可拦截高风险操作，当前为 **公开预览**。数据库审计负责重建访问过程，DAS Agent 辅助发现异常与风险。文章整合既有产品与方案，不代表所有能力均于当天首次上线。

## 四、平台工程与运维

### 5 Cloudflare 私有源站接入正式可用

发布机构：Cloudflare；作者：Enrique Somoza。原文日期：2026-10-30；官方 RSS 时间为 2026-10-30 14:23:43 UTC，即北京时间 10 月 30 日 22:23:43。首次发现：2026-10-31。

[原文：Cloudflare services for private origins is now generally available](https://blog.cloudflare.com/private-origins-public-to-private/)

该能力允许代理 DNS 记录指向私有 IP，通过已有 Cloudflare One 连接到达源站，使内部 API、Agent 后端及 MCP 服务可使用 WAF、限流、缓存和 Workers 等边缘能力，而源站保持私有地址。使用仍需账户权限和相应网络连接；当前不支持 Argo Smart Routing 与 Dedicated CDN Egress IPs，源站健康检查依赖 Load Balancing。此次正式可用范围是 **公网流量访问私有源站**；私网到私网仍是后续方向。
